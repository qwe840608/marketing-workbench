# トリアージラベル

> **言語 / Language / 語言 / 语言**：[繁體中文](../../zh-tw/agents/分類標籤.md) | [简体中文](../../cn/agents/分类标签.md) | [English](../../en/agents/triage-labels.md) | 日本語

skills は 5 つの標準的なトリアージの役割で話します。このファイルは、それらの役割をこのリポジトリの issue トラッカーで実際に使うラベル文字列に対応付けます。

| mattpocock/skills のラベル | このトラッカーのラベル | 意味                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | メンテナーがこの issue を評価する必要がある |
| `needs-info`               | `needs-info`         | 報告者からの追加情報を待っている         |
| `ready-for-agent`          | `ready-for-agent`    | 仕様が完全に決まっており、AFK エージェントが着手できる |
| `ready-for-human`          | `ready-for-human`    | 人による実装が必要                       |
| `wontfix`                  | `wontfix`            | 対応しない                               |

skill が役割に言及したとき（例：「AFK-ready のトリアージラベルを付ける」）は、この表の対応するラベル文字列を使ってください。

右側の列は、実際に使っている用語に合わせて編集してください。
