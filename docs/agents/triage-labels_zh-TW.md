# 分類標籤

> **語言 / Language / 语言 / 言語**：繁體中文 | [简体中文](triage-labels_zh-CN.md) | [English](triage-labels.md) | [日本語](triage-labels_ja.md)

skill 用五種標準的分類角色來描述議題。這份文件把這些角色對應到本 repo 議題追蹤裡實際使用的標籤字串。

| mattpocock/skills 的標籤 | 我們追蹤系統的標籤 | 意義                           |
| ------------------------ | ------------------ | ------------------------------ |
| `needs-triage`           | `needs-triage`     | 維護者需要評估這個議題         |
| `needs-info`             | `needs-info`       | 等回報者補充資訊               |
| `ready-for-agent`        | `ready-for-agent`  | 規格完整，可交給無人值守的 agent |
| `ready-for-human`        | `ready-for-human`  | 需要人來實作                   |
| `wontfix`                | `wontfix`          | 不會處理                       |

skill 提到某個角色時（例如「套用 AFK-ready 分類標籤」），使用上表對應的標籤字串。

右欄改成你實際使用的用詞即可。
