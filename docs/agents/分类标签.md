# 分类标签

> **语言 / Language / 語言 / 言語**：[繁體中文](分類標籤.md) | 简体中文 | [English](triage-labels.md) | [日本語](トリアージラベル.md)

skills 使用五个标准的分类（triage）角色。本文件把这些角色对应到本 repo 的 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估此 issue                   |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给无人值守（AFK）的 agent  |
| `ready-for-human`          | `ready-for-human`    | 需要由人来实现                           |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当 skill 提到某个角色时（例如“apply the AFK-ready triage label”，即“加上可交给 AFK agent 的分类标签”），使用上表中对应的标签字符串。

请编辑右侧的列，使其符合你实际使用的用词。
