# 介面翻譯術語表

> **語言 / Language / 语言 / 言語**：繁體中文 | [简体中文](../cn/i18n术语表.md) | [English](../en/i18n-glossary.md) | [日本語](../jp/i18n用語集.md)

翻譯 `frontend/src/locales/<語言>/` 時用這份表統一用詞。鍵是繁中原文，不可改鍵；`{變數}` 與前後空白要原樣保留。新增介面文字時三種語言都要補，術語照本表。

2026-10-19 依母語讀者角度整體校對過一次（AI 審稿，不是真人校對）。平台後台的按鈕與欄位名稱以各平台官方英文／日文／簡中介面為準；查不到或各版本說法不一的列在文末「待確認」。

## 寫作慣例

| 項目 | English | 简体中文 | 日本語 |
|---|---|---|---|
| 句型 | 句首大寫（sentence case）；按鈕用動詞開頭，不加句號；完整句子加句號 | 大陆用语，不直转繁中词汇；按钮简短 | 敬體（です・ます）；按鈕與標籤用體言止め，不加「。」 |
| 引號（指稱介面名稱） | “ ” | “ ” | 「 」 |
| 路徑箭頭 | → | → | → |
| 進行中狀態 | Saving… | 正在保存… | 保存中… |
| 失敗訊息 | Couldn't load … | …加载失败 | …を読み込めませんでした |
| 請使用者做事 | 直接用祈使句，少用 Please | 请… | …してください |
| 英數字與中日文之間 | — | 半形空白 | 半形空白（沿用原文排版） |

## 同一原文、不同譯法

翻譯表依群組合併，同一個鍵只會有一個譯文，後面的群組蓋掉前面的。所以同一個鍵在各檔的譯文必須相同；某個位置需要不同譯法時（例如英文導覽的 Settings 與按鈕的 Set），程式改用 `tx('情境', '原文')`，再在翻譯表加 `'情境|原文'` 的譯文。沒有情境譯文的語言自動用一般譯文，繁中畫面不受影響。
